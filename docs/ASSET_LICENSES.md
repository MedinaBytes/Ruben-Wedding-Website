## Approved approach

The orchid branch in `components/invitation/orchid-branch.tsx` is original, project-authored artwork and uses no external source material or attribution.

Prefer, in order:

1. Couple-provided photographs.
2. Custom SVG artwork authored for this project.
3. Open-source icon libraries with clearly documented licenses.
4. Public assets whose exact license has been verified.

Do not rely on a search result saying "free" without checking the asset's license/terms.

If a public asset requires attribution, include the required attribution in the appropriate legal/credits area.
