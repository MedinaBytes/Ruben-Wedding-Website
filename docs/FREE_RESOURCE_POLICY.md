# Free-First Resource Policy

The target is a high-quality wedding site using free/open-source resources wherever practical.

## Preferred stack/resources

- Next.js / React / TypeScript
- Supabase free tier where the project's usage fits its current limits
- Vercel Hobby where the project's use is eligible
- Sharp for local/build-time image processing
- Motion free/open-source skill + Motion React package
- GSAP npm package when advanced timelines are needed
- Lucide/Tabler-style open-source icon sets for generic UI icons
- custom SVG orchids for wedding-specific artwork

## Do not add by default

- paid animation libraries/features
- premium template subscriptions
- expensive image CDNs for a small wedding site
- marketing analytics platforms
- chat widgets
- ad networks
- autoplay audio services
- large animation packs that dramatically inflate the JS bundle

## Exception

A paid product can be discussed as a future option, but it must not silently become a required production dependency.
